🤖 Nicky – Assistente Pessoal de IA

Nicky é uma assistente pessoal inteligente, desenvolvida em Python, projetada para funcionar como um orquestrador de inteligências artificiais locais e 
externas, projetado para operar sobre todo o espectro do conhecimento humano — científico, social, simbólico e estratégico — aplicado à vida real.
O objetivo do projeto é substituir soluções pesadas por uma arquitetura leve, modular, extensível e observável, integrada ao ecossistema do 
servidor nickyserver.
O sistema não funciona como múltiplas IAs independentes, mas como uma única inteligência central (Nicky) que convoca perfis especializados conforme o contexto,
o risco e o objetivo.

🎯 Visão Geral
A Nicky não é apenas um chat.

Ela é um hub de inteligência pessoal, capaz de:

Integrar múltiplas IAs locais e externas
Operar via APP/Web, Bot Telegram e API interna
Assumir perfis de personalidade (Jarvis, Cortana, etc.)
Priorizar eficiência, baixo consumo de recursos e controle total

> **App Nativo + Motor LLM Avançado:**
> O objetivo é transformar a Nicky em um assistente comparável a
> Claude/ChatGPT em experiência de uso, acessível via app mobile (Android)
> e desktop (Windows/Linux), mantendo tudo local e privado.
> A interface web (chat.html) evolui para uma PWA instalável.
> O backend ganha streaming de respostas, contexto longo e API Key segura.

🧠 Conceito Central

🔐 Segurança
Chaves de API via variáveis de ambiente
Controle de custo por perfil
Logs claros e estruturados

- **Admin IDs**: lista de IDs Telegram com acesso a comandos administrativos, definida em `.env`
- **CORS**: configurado como `allow_origins=["*"]` — restringir em produção se exposto publicamente
- **Credenciais**: nunca versionadas (`.env` no `.gitignore`)
- **Rate limiting**: protege o LLM LOCAL de sobrecarga por spam
- **Tailscale**: acesso remoto via VPN mesh sem exposição de portas ao público
